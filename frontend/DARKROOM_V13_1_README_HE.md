# ProGrapher V13.1 — Darkroom UI

השדרוג מתמקד בדיוק בשתי נקודות:

1. הטיפוגרפיה של ה-Darkroom הוגדלה כדי שהעורך לא ירגיש כאילו הממשק מוקטן.
2. לכל Slider יש עכשיו Track שממחיש את כיוון ההשפעה:
   - טמפרטורה: כחול → חם
   - חשיפה: כהה → בהיר
   - Highlights / Shadows / Whites / Blacks: טווח טונאלי רלוונטי
   - Vibrance: אפור → צבעוני

נוסף גם סימון מרכז (0), Thumb מעט גדול יותר, ופאנל עריכה רחב יותר.
אין שינוי ל-Backend ואין שינוי בלוגיקת העריכה.
