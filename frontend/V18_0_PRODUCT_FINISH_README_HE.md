# ProGrapher Frontend V18.0 — Product Finish

## "הסגנון שלי" נבנה מחדש

המסך הרגיל של הצלם מציג עכשיו רק:
- Profile פעיל + גרסה.
- החלטות שנלמדו.
- אישורים / תיקונים.
- Acceptance Rate אמיתי כאשר קיים.
- מקור הסגנון.
- תיאור הסגנון והעדיפויות מה-Onboarding.
- התקדמות לגרסה חדשה.
- Candidate חדש והפעלה מפורשת.

הוא לא מציג:
- MAE / P90 / P95
- Dataset Integrity
- Vision Embeddings
- CUDA / CLIP internals
- Sparse / Suspicious / Provenance
- V1 / V2 comparisons
- Feature Importance / Prediction Inspector

## Guided Setup

- איתור קטלוג.

- רק כפתור הפעולה הבא שהצלם באמת צריך מופיע.
