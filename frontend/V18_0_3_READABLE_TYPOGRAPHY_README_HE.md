# ProGrapher Frontend V18.0.3 — Readable Typography Hotfix

This hotfix corrects the photographer-facing typography in:
- My Style
- Lightroom Profile Setup

Rule applied:
- No meaningful product copy under 12px.
- Body/help text is generally 13–16px.
- Section labels are 12–13px.
- Card headings are larger.
- Hero copy is substantially larger.
- Buttons are at least 13px and 42px tall.
- Spacing was increased so larger text does not feel cramped.

Developer Diagnostics was intentionally not enlarged; this pass targets the
normal photographer product experience.
