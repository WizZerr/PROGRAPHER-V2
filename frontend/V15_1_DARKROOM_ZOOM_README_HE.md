# ProGrapher Frontend V15.1 — Darkroom Zoom Fix

## שינויים
- הוסר Zoom בגלגלת.
- לחיצה על נקודה בתמונה ב-100% מבצעת Zoom ל-200% סביב הנקודה שנבחרה.
- כאשר התמונה מוגדלת ניתן לגרור אותה.
- Double-click מחזיר ל-Fit / 100%.
- כפתורי +/- נשארו למי שרוצה Zoom מדויק.
- אזור מקור/ערוך מוגבל עכשיו לגבולות התמונה עצמה.
  לכן ה-labels והקו לא יושבים יותר בתוך שטח שחור מת.
- מקור וערוך משתמשים באותו Stage ובאותה טרנספורמציה,
  כדי לשמור התאמה מדויקת בזמן השוואה.
