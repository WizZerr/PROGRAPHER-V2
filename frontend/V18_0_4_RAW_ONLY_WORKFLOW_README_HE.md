# ProGrapher Frontend V18.0.4 — RAW-only Production Workflow

- New events accept RAW files only.
- JPG/PNG/WEBP are rejected before upload.
- File picker is limited to supported RAW extensions.
- Darkroom explicitly labels the browser render as a RAW local preview.
- Lightroom/XMP is presented as the authoritative final render.

No database reset is required.
