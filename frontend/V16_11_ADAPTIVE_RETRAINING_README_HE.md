# ProGrapher Frontend V16.11 — Adaptive Retraining

שלב 6 של Closed Loop V1.

בראש "הסגנון שלי" נוסף כרטיס מוצרי קטן שמציג:
- גרסת Profile פעילה.
- כמה החלטות למידה נאספו.
- כמה אושרו וכמה תוקנו.
- התקדמות ל-20 Decisions.
- מצב בניית Candidate.
- Candidate חדש כשהוא מוכן.
- כפתור הפעלה מפורש.

אם Validation לא השתפר:
ProGrapher מציג שהפרופיל הפעיל נשאר טוב יותר ולא מחליף אותו.

המסכים הישנים של R&D נשארו כרגע מתחת לכרטיס החדש.
ניקוי/הסתרת ה-R&D הוא שלב UX נפרד ולא חלק מ-Retraining.
