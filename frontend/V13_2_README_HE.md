# ProGrapher V13.2 — UX Fixes

השינויים בגרסה:

- תיקון התנגשות בין הסליידרים לכפתורי השמירה ב-Darkroom.
  כעת רק אזור הסליידרים נגלל וה-footer נשאר באזור נפרד.
- תיקון התוויות לפני / אחרי בהשוואת התמונה.
- העמוד הישן "בדיקה ואישור" הוסר מהתפריט.
- עמוד האירועים עבר מרשימה לגריד של כרטיסים:
  4 כרטיסים בשורה ברוב מסכי Desktop ו-5 במסכים רחבים מאוד.
- בכל כרטיס אירוע מוצג גם תאריך האירוע.
- תאריך ברירת המחדל ביצירת אירוע הוא היום לפי המחשב המקומי.
- אייקון לוח השנה ב-input של תאריך הותאם לרקע הכהה.
- סוגי האירועים הם:
  חתונה, בר מצווה, בת מצווה, חינה, אחר.
- בבחירת "אחר" מופיע שדה להזנת סוג האירוע.
