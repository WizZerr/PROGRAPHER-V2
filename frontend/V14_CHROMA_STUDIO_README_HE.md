# ProGrapher V14 — CHROMA STUDIO

מטרת הגרסה היא לצאת מהמראה הגנרי של Dashboard/AI SaaS ולעבור לשפה שמתאימה למוצר של צלמים ועורכי צבע.

## שפה חזותית
- רקע גרפיט עמוק ונייטרלי לעריכת צבע.
- ספקטרום צבע עדין שמשמש כחתימה, לא כ-gradient גנרי בכל כפתור.
- טיפוגרפיה מבוססת Segoe UI Variable / Segoe UI ללא קובצי font חיצוניים.
- טקסטים גדולים ומרווחים יותר בכל הממשק.
- Panels נקיים יותר, עם פחות כחול-סגול גנרי.

## עמוד אירועים
- Hero מרווח עם ספירת אירועים וכפתור יצירה.
- כרטיסי אירוע גדולים בהרבה.
- לכל סוג אירוע יש חתימת צבע שונה.
- אזור ספקטרלי בכל כרטיס שנותן תחושה של סביבת צילום / grading.
- שם אירוע 22px עם font מודרני ועקבי בעברית.
- Metadata ברור ומרווח.
- CTA חדש: "כניסה לסביבת העבודה".
- מחיקה נשארת secondary action ועדינה עד Hover.

אין שינוי Backend.
