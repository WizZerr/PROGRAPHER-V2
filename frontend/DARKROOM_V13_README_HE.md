# ProGrapher Frontend V13 — Darkroom

מסך פרטי התמונה הוחלף ל-Workspace עריכה בסגנון Lightroom Classic:

- התמונה נמצאת בצד שמאל ותופסת את רוב המסך.
- כל בקרי העריכה נמצאים בפאנל צר בצד ימין.
- אין יותר כרטיסי Metadata שתופסים את אזור העבודה.
- Metadata ונתוני קובץ עברו למקטע מתקפל מתחת לתמונה.
- ניתוח AI מפורט עבר למקטע מתקפל מתחת לתמונה.
- סליידרים מקובצים לפי צבע / גוון וטון / נוכחות.
- שינוי סליידר יוצר Preview תיקון אוטומטי מול העיניים.
- מוצג ערך AI ליד סליידר ששונה.
- דאבל-קליק על סליידר מחזיר אותו לערך ה-AI.
- פעולות מקור / לפני-אחרי / ערוך נמצאות מתחת לתמונה.
- ב-Training Review יש הקודם / הבא + מונה התקדמות בראש ה-Darkroom.
- שמירה ואישור נשארים תמיד נגישים בתחתית פאנל הבקרים.

לא נדרש שינוי Backend מעבר ל-V1.0 Training Review שכבר מותקן.
