# ProGrapher — Photographer Submission Checklist

> **ארכיון בדיקות JPEG בלבד — לא דרישת קליטה פעילה.** למסלול הנוכחי: `.lrcat` + `Smart Previews.lrdata` תואמות, ללא RAW היסטורי, כפי שהוחלט ב־[D-022](D_022_HISTORICAL_SMART_PREVIEWS_CONTRACT.md). בחירה מקומית ולא העלאת חומר אישי ל־GitHub. בדיקות הזהות, סופיות ותצוגה נקייה מעריכה עדיין פתוחות.


Version: **1.0**

לפני שמעבירים חומר ל-Intake:

- [ ] כל Event נמצא בתיקייה נפרדת.
- [ ] בכל Event קיימות `ORIGINALS/` ו-`EDITS/`.
- [ ] ORIGINALS הם המקורות האמיתיים ששימשו לעריכה ולא export מחודש.
- [ ] EDITS הם ה-Final שהצלם מחשיב מוכן למסירה.
- [ ] filenames נשמרו ככל האפשר בין Original ל-Edited.
- [ ] אירועים שונים אינם מעורבבים.
- [ ] תוכנת העריכה וה-workflow תועדו.
- [ ] Color Space / export policy תועדו ככל הידוע.
- [ ] מצלמות ותנאי תאורה תועדו ככל הידוע.
- [ ] Crop / retouch / Photoshop / local edits חריגים צוינו.
- [ ] תמונות שנשארו בכוונה ללא שינוי סומנו במפורש.
- [ ] RAW/XMP, אם נמסרו, נמצאים בנפרד ממסלול JPEG.
- [ ] הצלם אישר שיש לו הרשאה לשתף את החומר בהיקף הניסוי המוסכם.
- [ ] לא שינינו קובצי מקור כדי "לסדר" את ה-Dataset לפני Intake.
